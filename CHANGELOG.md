# Changelog

## 1.2.0 - 2026-10-16

- Added opt-in effective action and method variants for enabled submit controls, including external associations and image coordinate names.
- Respect the first href-bearing base element, including empty values, and restrict submitters to input/button elements.
- Compare submission overrides against saved HTML baselines without changing default reports.

## 1.1.0 - 2026-09-07

- Resolve supported static accessible-name patterns, external form associations and source locations; compare saved HTML forms.
- Added regression coverage for the audited behavior and invalid inputs.

## 1.0.0 - 2026-07-26

- Released the first complete Web Form Field Inventory command-line workflow.
- Added deterministic reporting, representative examples, cross-platform tests, and explicit limitations.
